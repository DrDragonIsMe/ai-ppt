# 期末复习实操：用 ai-ppt 把错题和知识卡片变成复习课件

> 场景：学生党/自学者期末周的真实动线——平时积累的知识卡片和错题，如何在 ai-ppt 里完成「复习训练 → 智能组卷 → 生成复习课件」的闭环。文中所有按钮与入口名称均与产品界面一致。

## 平时：知识卡片是复习的本体

我的知识库里存着一组卡片：数学的「勾股定理」「二次函数」，化学的「元素周期律」，每张卡片都有问题、答案、解析和熟练程度（1-5 级）。这些卡片可以手写，也可以让 AI 帮忙：打开任意一篇笔记或卡片，点「✨ AI 扩展知识」，系统会把相关知识点展开，确认后一键「创建知识卡片」。

卡片不是死数据。每次复习时按掌握情况点「不记得 / 有点印象 / 基本掌握 / 掌握得好 / 完全掌握」，熟练度就成了后续所有智能功能的输入。

![截图：知识卡片 tab 的卡片详情与熟练度评分](shots/study-card.png)

## 第一步：复习训练，先自测一遍

侧边栏切到「学习」tab，再切到「复习训练」子页，两个入口摆在眼前：

- 「📚 复习知识卡片」：按熟练度和到期情况抽卡，先自己想答案，点「显示答案」对照，然后如实评分（从「😵 完全忘记」到「🎉 完全掌握」）；
- 「❌ 攻克易错题」：专门针对错题集里的题目来过一遍。

评低分的卡片会被系统记住，在后续的组卷和复习中优先出现。这就是「到期复习」的含义：不需要自己记账，系统帮你盯着哪些知识该回炉了。

![截图：复习训练答题界面与评分按钮](shots/study-training.png)

## 第二步：错题集，自动归集 + 手动补充

测验或训练中答错的题会自动进入「错题集」子页。也可以手动「+ 记录错题」——比如作业里的一道典型错误，填上题目、正确答案、错因分析。错题集支持按分类和熟练度筛选（需要复习 / 基本掌握 / 完全掌握），顶部统计区实时显示「道错题 / 次复习 / 道已掌握」。

确认真正搞懂的错题，点「✅ 标记已掌握」，它就从待复习队列里毕业了。

![截图：错题集列表与筛选](shots/study-mistakes.png)

## 第三步：智能组卷，检验复习效果

复习完一轮，该检验了。「学习」tab 的「测验」子页点「智能组卷」（工作台首页的快捷操作里也有同款按钮），系统会从三个池子里选题：低熟练卡片、到期复习卡片、历史错题。配置了大模型时会生成变式题——不是简单复述卡片，而是换个角度考你；没配置模型时降级为直接选题，功能不受影响。

生成的试卷可以在线作答，答错的新题继续回流到错题集，形成「复习 → 测验 → 错题 → 再复习」的循环。

![截图：智能组卷生成的新试卷](shots/study-exam.png)

## 第四步：一键生成复习课件

这是我最喜欢的一步。两个入口：

- 「错题集」子页的「生成复习 PPT」：把筛选后的错题变成一份复习课件；
- 「知识卡片」tab 的「生成复习 PPT」：把选中的卡片变成课件。

生成的 deck 进入「PPT 作品」tab，走标准的四步流水线：选材 → 生成 → 修改 → 发布。我通常会先跑一次「设计检查」，再用「AI 修改」微调（比如「每页只保留一道题，解析放到演讲者备注」），然后「导出 ▾」选「视频 MP4」发到平板上躺着看，或者「发布」生成二维码，自习时用手机扫码翻页。

![截图：错题集的「生成复习 PPT」按钮](shots/study-review-deck.png)

## 小结

复习的痛点从来不是"没有资料"，而是资料散落、不知道从何看起。ai-ppt 把卡片熟练度、到期复习、错题归集串成一条线：先训练自测，再组卷检验，最后把薄弱环节一键变成课件。期末周，至少不用再手抄错题本了。
