# HR 的一天：从会议录音到培训 PPT 投屏，只要一条流水线

> 场景：HR 每周都要把零散的会议内容、产品资料变成培训材料。这篇文章记录我用 ai-ppt 把一段 27 分钟的会议录音变成一套入职培训 PPT 并投屏放映的完整动线，所有功能路径均与产品实际界面一致。

## 起点：一段会议录音

周一的产研对齐会开了 27 分钟，内容涉及产品模块调整和定价讨论。过去我要么边听边敲纪要，要么会后对着录音反复拖进度条。现在的做法是：打开 ai-ppt 的 Web 界面（`npm run web`），左侧切到「速记」tab，点输入框旁边的 🎙 按钮，弹出「语音听记」窗口开始录音；也可以直接把已有的录音文件作为附件丢进速记。

录音提交后会变成一条带 `voice-*.webm` 附件的速记碎片，系统自动走解析流程——我的知识库里现在就躺着两条这样的笔记：「🎙 语音听记 15:27（时长 27:12）」，正文里是可回放的音频条，下面跟着一整块「📎 解析」结果：分点的内容摘要、关键结论，以及自动提取的 `#ToB AI` `#产品定价` 这样的标签。

![截图：速记 tab 中的语音听记按钮与解析后的碎片](shots/hr-fragment-voice.png)

## 第二步：AI 整理，把碎片归置到位

录音碎片只是原材料。点碎片面板的「AI 整理」，系统会逐条给出建议：这条升格为笔记、那条补标签、另一条关联到已有的《薪人薪事产品介绍》笔记。逐条确认后，碎片就从「待整理」收件箱进入知识库，成为可以长期沉淀的资产。

对我来说最有价值的是双链：整理后的笔记里用 `[[招聘管理模块]]`、`[[薪酬考勤系统]]` 这样的 wikilink 把相关内容串起来。下次做薪酬主题的培训时，打开「知识星图」面板，勾选「只看高频」，就能一眼看到哪些笔记是整个知识库的中心节点——它们通常就是我培训材料的主线。

![截图：知识星图面板，勾选「只看高频」](shots/hr-graph.png)

## 第三步：一键生成培训 PPT

打开整理好的笔记，点工具栏的「生成 PPT」，在弹窗里设置标题（比如「新员工入职培训 · 产品篇」）、受众（新入职同事）、风格（培训课件）和页数，确认后开始生成。生成过程实时显示进度；即使没配置大模型，系统也会按确定性模板产出一版可用的幻灯片，不会卡住。

生成完成后别急着用——点工作区的「设计检查」，系统会跑一遍排版校验：一行大数字是否超过 4 个、标题是否过长、版式是否重复、表格是否过密。发现的安全类问题可以一键修复。这一步把「一眼 AI」的幻灯片挡在了门外。

![截图：项目工作区，设计检查结果](shots/hr-design-lint.png)

## 第四步：改成自己的话，再测验巩固

初稿难免有需要调整的地方。两个工具配合用：

- 「编辑模式」：直接在幻灯片上点选文字修改，手动改动会被记录下来，后续 AI 重新生成也不会覆盖；
- 「AI 修改」：用自然语言下指令，比如「把产品模块那页换成两栏布局」，AI 只返回修改的页，其余页原样保留，改完还会列出修改明细。

培训不能只讲不练。切到侧边栏「学习」tab，在「测验」子页点「智能组卷」，系统会从低熟练卡片、到期复习卡片和历史错题里选题，自动生成一份测验。我的知识库里就有一份「新员工入职培训测验」，5 道题，培训结束后投屏让新人现场作答，答错的题自动进「错题集」，下次培训前还能一键「生成复习 PPT」。

![截图：学习 tab 的测验子页与智能组卷](shots/hr-exam.png)

## 收尾：发布，扫码投屏

培训当天，点工具栏的「发布」，系统把整套 deck 打成一个递增版本，弹出「发布成功」窗口：完整链接、「复制链接」按钮和二维码。会议室里用手机扫码就能打开放映页，方向键翻页、按 `T` 换主题、按 `F` 全屏、按 `Shift+S` 进演讲者模式（带备注和计时）。需要给手机扫码的同事注意：服务要用 `AI_PPT_HOST=0.0.0.0` 启动，并且手机在同一局域网。

如果需要把材料发进群里，「导出 ▾」一个入口搞定：PPTX（可编辑文字）、高清图片 PPTX、浏览器打印 / PDF、单文件 HTML、视频 MP4、静态站点包 ZIP，按需取用。

## 小结

整条动线：会议录音 → 语音听记 → 速记碎片 → AI 整理 → 笔记/星图 → 生成 PPT → 设计检查 → AI/可视化修改 → 智能组卷 → 发布二维码投屏。材料不再是一次性消耗品，而是沉淀进知识库、下次可复用的资产。
