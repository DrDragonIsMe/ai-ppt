# 从散会到汇报：30 分钟把会议纪要变成一份像样的 PPT

> 场景：周会刚结束，下午就要向领导汇报。这篇文章记录我用 ai-ppt 把会议内容变成汇报 PPT 的完整过程：语音听记 → 双链整理 → 生成汇报 PPT → AI 对话修改 → 导出 PPTX/PDF/视频。所有操作路径与产品实际界面一致。

## 会中：语音听记，先把自己解放出来

开会时最难受的是边听边记——记了就听不全。ai-ppt 的做法是：Web 界面（`npm run web`）左侧「速记」tab，点输入框旁的 🎙 按钮打开「语音听记」弹窗，开始录音，专心开会。

录音提交后成为一条带音频附件的速记，系统自动解析：正文里先是一个可回放的音频条（`voice-*` 录音渲染为 `<audio>`），下面跟着「📎 解析」块——分要点的内容摘要和自动提取的 `#标签`。我的知识库里有两条真实的听记笔记，27 分钟的会议被整理成定价策略、产品定位、落地实践三组要点，比自己手忙脚乱记的完整得多。

![截图：语音听记弹窗与解析后的听记笔记](shots/meeting-voice.png)

## 会后十分钟：双链整理，把纪要挂进知识网络

听记只是原料。点碎片面板的「AI 整理」，系统建议这条听记升格为笔记，并自动带上 `[[ToB AI产品方法论]]` 这样的双链。别小看这些链接——它让这次会议和之前的相关笔记产生了连接。

我的做法是为会议维护一个「会议纪要模板」知识卡片，整理时把行动项补进笔记，再用 wikilink 挂上相关项目笔记。日积月累，打开「知识星图」，会议笔记之间的引用关系一目了然；汇报前想快速定位重点，勾上「只看高频」，权重最高（链接多、被反复提及）的节点就是汇报该讲的重点。

![截图：知识星图中的会议笔记节点](shots/meeting-graph.png)

## 生成：从笔记到汇报 PPT

打开整理好的会议纪要笔记，点工具栏「生成 PPT」，设置标题（如「Q3 产研对齐会汇报」）、受众（管理层）、风格、页数，确认生成。系统按「大模型 → CLI → 确定性模板」多级降级产出幻灯片——即便完全没配模型，也会给你一版结构完整的兜底稿。

生成完先点「设计检查」：一行大数字超没超 4 个、标题是否过长、版式有没有连续重复、表格是否太密，十几项校验一次跑完，安全类问题一键修复。

![截图：生成进度与设计检查结果](shots/meeting-generate.png)

## 修改：和 AI 聊两轮，比自己拖拽快

初稿到手，进入「修改」阶段。点工作区的「AI 修改」，用自然语言下指令：

- 「把第二条定价策略展开成单独一页」
- 「整体语气再正式一点，删掉口语化表达」
- 「结尾页加一页下一步行动项」

AI 只返回修改的页，其余页原样保留——之前手动调过的内容不会被冲掉。每轮修改完成还会列出修改明细，聊天记录持久保存，刷新页面也能回顾。个别字眼不顺手的，开「编辑模式」直接在幻灯片上点选修改即可。

![截图：AI 修改对话与修改明细](shots/meeting-chat.png)

## 交付：一个入口，三种格式

汇报场景不同，要的格式也不同。工具栏「导出 ▾」（快捷键 `Ctrl+P`）一个入口全包：

- **PPTX（可编辑文字）**：发给领导前他还要改两笔，选这个；
- **高清图片 PPTX**：逐页截图，还原度最高，跨机器不怕字体缺失；
- **浏览器打印 / PDF**：正式归档用；
- **视频 MP4**：每页 4 秒自动翻页，适合发群里异步传阅；
- **单文件 HTML / 静态站点包 ZIP**：发给外部或丢到任何静态托管。

现场汇报则直接点「发布」，弹出窗口给出链接、二维码；放映页按 `Shift+S` 进入演讲者模式，备注、下一页预览、计时器都在。

![截图：导出下拉与发布成功弹窗](shots/meeting-export.png)

## 小结

这条动线的关键是"资产不浪费"：录音变成听记，听记整理成带双链的笔记，笔记生成 PPT，PPT 改完导出/发布——会后所有产物都留在知识库里，下次写周报、月报时，「选材」勾一下就是现成的素材。
