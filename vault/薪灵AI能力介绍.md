# 薪灵AI能力介绍

薪灵AI是薪人薪事打造的企业级智能能力平台，以「虚拟员工」为核心产品形态，通过RAG知识引擎、Skill能力库与Token管控底座，连接HR SaaS、费控、OA、IM、CRM等企业系统，为企业提供可编排、可扩展、可度量的AI生产力。

![[xinling-ai-architecture.svg]]

## 整体架构

薪灵AI生态架构分为三层，自下而上依次为：

1. **数据基建层**：企业各系统CLI接入 + 对应Skills安装 + 多模态模型能力
2. **AI能力层（薪灵AI）**：RAG知识引擎 + Skill与AI开发插件 + Token管控与终端接入
3. **虚拟员工层**：生产与共创平台 + 虚拟员工实例（运营/客服/HR专项等）

数据自下而上流动：系统数据与模型能力输入AI能力层，经RAG、Skill编排与Token管控后，以虚拟员工的形态对外提供服务，并持续反馈迭代。

## 数据基建层

数据基建层是薪灵AI的数据源与能力底座，通过各系统CLI与对应Skills实现企业系统能力的原子化接入。

### 薪人薪事CLI（核心）
- 覆盖考勤、薪酬、招聘、培训、绩效五大HR核心模块
- 对应HR Skills，提供人力资源全场景原子能力
- 是虚拟员工最核心的业务能力来源

### 周边系统CLI
- **费控CLI**：报销、预算、对账 → 费控Skills
- **OA CLI**：审批、流程、日程 → OA Skills
- **IM CLI**：消息、群管、通知 → IM Skills
- **CRM CLI**：客户、线索、工单 → CRM Skills

### 模型能力
- 工具模型：任务理解、工具调用、推理规划
- 视觉模型：图片理解、文档解析、图表识别
- 视频模型：视频生成、数字人、内容创作

## 薪灵AI能力层

薪灵AI是整个架构的核心中枢，提供三大能力支柱：RAG知识引擎、Skill与AI开发插件、Token管控底座。

### RAG知识引擎
- **知识检索增强**：基于向量数据库的语义召回，精准匹配企业知识库内容
- **上下文构建**：Prompt智能组装 + 多路召回融合，确保回答准确全面
- **企业级RAG Pipeline**：完整的知识接入、清洗、切片、索引、检索、重排流水线

### Skill与AI开发插件
- **通用Skill库**：复用型原子能力，跨场景调用，一次开发多处使用
- **AI开发插件**：自定义扩展、API封装、生态集成，满足企业个性化需求
- **Skill注册与编排**：可视化编排引擎，企业可定制专属AI工作流

### Token管控（NewApi）
- Token计量：精确到调用级的Token消耗统计
- 成本核算：按部门/项目/人员维度的AI成本分摊
- 配额管理：灵活的额度配置与超用预警
- 模型路由：智能选择最优模型，兼顾效果与成本
- 缓存与复用：相似请求缓存命中，降低重复消耗
- 终端接入：支持软件终端与硬件终端统一接入管控

## 虚拟员工层

虚拟员工是薪灵AI的最终产品形态——不是聊天机器人，而是具备岗位能力、可独立完成工作的AI员工。

### 虚拟员工生产与共创

**生产流程**：需求定义 → Skill编排 → RAG配置 → 测试上线
- 像装配生产线一样"生产"虚拟员工
- 标准化流程，可复制、可规模化

**共创流程**：用户反馈 → Skill迭代 → 知识库更新 → 版本发布
- 虚拟员工在使用中持续进化
- 用户反馈驱动能力迭代闭环

### 虚拟员工实例

**运营员工**
- 生产调度：管理虚拟员工的任务分配与执行
- 共创管理：协调多虚拟员工协同工作
- Token/RAG监控：实时监控AI资源使用与效果

**企小薪客服**
- CLI命令管控：通过自然语言驱动各类系统操作
- 软硬一体服务：支持软件对话 + 硬件终端接入
- 知识库+Skill：知识问答 + 业务操作一体化

**HR招聘专员**
- 简历智能筛选：自动解析简历、匹配岗位要求
- 面试日程安排：自动协调候选人与面试官时间
- 人才匹配推荐：基于人才画像智能推荐合适岗位

**HR薪酬专员**
- 薪资自动核算：按规则自动计算工资、奖金、扣款
- 社保个税申报：自动对接社保与个税系统完成申报
- 薪酬政策问答：员工关于薪酬的问题随时解答

**HR培训专员**
- 培训课程推荐：根据岗位与能力短板推荐课程
- 学习进度跟踪：监控员工学习进度与成果
- 企业知识更新：自动维护企业知识库的时效性

## 硬件与生态

- **硬件外包合作**：专注虚拟员工"大脑"的生产，硬件终端由专业外包伙伴提供与集成
- **开放生态**：支持第三方Skill接入、企业自定义插件、多模型接入
- **安全合规**：企业级数据安全保障，私有化部署可选

## 核心价值

1. **降本增效**：虚拟员工7×24小时工作，替代大量重复性HR事务，人力成本降低40%+
2. **可度量**：Token级成本核算，每个虚拟员工的投入产出清晰可见
3. **可扩展**：Skill化的能力架构，新增业务场景只需开发对应Skill
4. **持续进化**：基于真实使用反馈的共创机制，越用越聪明
5. **一体化**：HR SaaS + AI原生设计，数据天然打通，无需额外集成
